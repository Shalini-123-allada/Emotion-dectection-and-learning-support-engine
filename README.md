# 😊 Emotion Detection and Learning Support Engine

An AI-powered application designed to support personalized learning through emotion detection and intelligent learning assistance.

## 📌 Project Overview

The Emotion Detection and Learning Support Engine is designed to identify emotional states and provide personalized learning support. The system aims to create a better learning experience by combining Artificial Intelligence and Machine Learning technologies.

It focuses on understanding emotional information and supporting students with suitable learning assistance.

## ✨ Features

- 😊 Emotion Detection
- 🤖 AI-Based Learning Support
- 🧠 Machine Learning Integration
- 📚 Personalized Learning Assistance
- 📊 Learning Support Reports
- 🧪 Testing and Evaluation
- 💻 User-Friendly Application Structure

## 🏗️ Project Architecture

The project is organized into different modules for application development, data management, model storage, testing and reporting.

## 🚀 Getting Started

### Prerequisites

- Python
- pip (Python Package Manager)

### Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Install the required dependencies using:

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```
